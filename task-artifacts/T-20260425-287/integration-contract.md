## Non-negotiable release truth

0.4.48 may be framed as a release-quality tranche only if the merged result proves three things together:

1. **Cold-start**: fresh/new-home routing starts from a stronger approved prior without bypassing eligibility, provenance, or replay gates.
2. **Learned-route**: the live learned `route_fn` path remains central, observable, and replay-gated; cold-start and Graphify additions feed it rather than replace it.
3. **Graph maintenance**: Graphify/graph-maintenance surfaces are off-path diagnostic/compiler artifacts with registry/provenance links, not live current-truth authority.

If any lane misses its bar, the release note must narrow to the lanes that actually landed and explicitly mark the other lane as target/follow-up.

## Lane exit bars

### A. Cold-start lane

Must exit with all of:

- A deterministic fresh-home/cold-start path that can load an approved router export or approved prior artifact without using review-only rows.
- Eligibility filtering remains strict (`approved_train` / equivalent governed eligibility only); synthetic fixtures remain labeled synthetic.
- Replay/smoke coverage proves the cold-start prior can be loaded, trained/replayed, and rejected/failed closed when malformed or ineligible.
- Operator/proof or status surface exposes enough lineage to distinguish: base prior, inherited learned-route family, retrain lineage, and fixture/sample vs real approved export.
- No claim that cold-start proves broad answer quality, long-run personalization, or live graph self-editing.

Minimum proof/tests:

- Focused tests covering loader/trainer/runtime/replay gate, normally including relevant existing tests such as `cold-start-router-approved-export-loader`, `cold-start-router-trainer`, `cold-start-router-runtime`, `cold-start-router-replay-gate`, and source-intake/export candidate tests.
- A compact artifact/report under `task-artifacts/T-20260425-287/` naming the exact approved export or fixture, eligibility counts, commands run, and boundary.

### B. Learned-route lane

Must exit with all of:

- Runtime path still selects/uses the learned `route_fn` family when mode is learned; any new prior/import is subordinate to promoted pack and route policy.
- Route decision/outcome events expose attribution that separates learned-route use, approved prior fallback, graph prior/import influence, vector-only behavior, and no-brain/fail-open behavior.
- Comparative eval/reporting separates unique wins, ties, regressions, and keep-clean negatives; no ties-as-wins language.
- Replay gate blocks regressions and records exact manifest/input/hash lineage.
- Current explicit corrections and newer preference precedence remain above learned/graph-derived priors.

Minimum proof/tests:

- Focused route mission or equivalent: `npm run test:learned-route-mission` if still valid after merge, or the named subset with route-decision, route-outcome, trainer/runtime/replay, and graphify-training-bridge coverage.
- If decision-quality claims broaden, run/refresh a frozen replay/eval bundle (`npm run proof:frozen-eval-gate` or equivalent lane command) and cite the resulting `summary.md` plus machine tables.
- A lane report under `task-artifacts/T-20260425-287/` with exact eval manifest, counts for better/tied/worse, and remaining boundaries.

### C. Graph-maintenance lane

Must exit with all of:

- Graphify/graph-maintenance remains off the serve path and cannot become current-truth authority.
- Delta/reorg/maintenance outputs are registry-linked and replayable from their source bundle/hash plus downstream artifacts.
- Import/training bridges admit only EXTRACTED eligible context into candidate training/import paths; INFERRED/AMBIGUOUS/provenance-gap hints remain review-only.
- Maintenance diff/lint outputs are bounded diagnostics and explicitly cite whether each surface is shipped, target, or review-only.
- Retention/vacuum behavior never silently prunes registry-referenced artifacts.

Minimum proof/tests:

- Focused graph maintenance tests for scheduler/registry, graphify bridge/training bridge, final replay proof, and any maintenance diff/lint surfaces touched.
- A compact run artifact or fixture proving registry entry shape, linked artifact paths, retention policy, and replayability notes.
- A lane report under `task-artifacts/T-20260425-287/` naming exact commands and confirming no hot-path dependency was added.

## Forbidden overclaims

Do not claim any of the following unless a separate, explicit proof bundle exists and the release contract is updated honestly:

- "Broad memory is solved" or "OpenClawBrain now generally improves answer quality."
- "Cold-start proves long-run personalization" or "fresh homes are equivalent to trained homes."
- "Graphify is the live runtime / source of truth / answer engine."
- "Teacher v3 or graph maintenance mutates live graph truth automatically."
- "No regressions" without naming exact corpus/manifest and showing the regression count.
- "Wins" when the evidence is tied/no-regression guardrail evidence.
- "0.4.48 is shipped/published" before npm publish/tag/release/install proof are complete.

## Merge order recommendation

1. **Cold-start first** — it likely touches approved exports, trainer/runtime contracts, and lineage surfaces that route evaluation depends on.
2. **Learned-route second** — reconcile route-decision/outcome/event schema and replay gates after the cold-start prior shape is known.
3. **Graph-maintenance third** — wire registry/import/review artifacts against final route-row and candidate-pack shapes while preserving off-path boundaries.
4. **Integration/release prep last** — run combined focused tests, update release notes/version surfaces, then release-plan/docs-drift gates.
